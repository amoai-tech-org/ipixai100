## Progress UX state machine

```mermaid
stateDiagram-v2
  [*] --> Listening: subscribe brands + brand_crawls
  Listening --> LiveProgress: postgres_changes event
  LiveProgress --> Listening: more events
  Listening --> StillWorking: quiet gap warning
  StillWorking --> LiveProgress: event arrives
  Listening --> ConnectionLost: CHANNEL_ERROR or TIMED_OUT
  ConnectionLost --> Listening: Reconnect
  Listening --> Failed: server intake_status failed
  LiveProgress --> Failed: server intake_status failed
  LiveProgress --> Ready: intake_status ready
  Failed --> Listening: Retry kickoff
  Ready --> [*]
```

**Pinned rule:** the client never decides a run has failed. Only the server does.
